StavanHow it was made

This is a real page from my graph theory notes. Scroll to watch it get taken apart, stroke by stroke, until five of its letters end up in the font.

The page

I wrote this in a lecture with an Apple Pencil in GoodNotes. It's one of 675 pages that went into the font.

Every stroke

GoodNotes doesn't keep a picture of the page. It keeps every stroke as the exact path the pen took, in order. This page has 496 of them, each coloured differently here.

Words

Strokes that sit close together on a line are grouped into words. There are 112 on this page.

Letters

Inside each word, strokes that overlap are grouped into letters. An AI model read thousands of words like these, and each letter it read was matched back to its strokes.

The keepers

Most letters are fine but ordinary. From this page, five were picked to be in the font because they look the most like how I usually write them, while still looking different from the others.

The font

Every letter gets five versions from five different pages. The one from this page sits next to four others, and they take turns as you type.

Now write with it

705 letters from 675 pages, packed into a font you can type with, download, or watch write itself.
