What you're looking at

Every letter on this page was cut out of real Apple Pencil strokes from my GoodNotes notes: lectures, proofs, assignments, practice exams. Nothing was traced from photos and nothing was redrawn. Each letter and digit has five versions taken from different pages. They take turns as you type, so the same word never comes out the same twice. “Watch it write” replays the actual pen strokes in the order I wrote them.

code in my handwriting

Stavan Mono is the same handwriting squeezed into equal-width cells, so code still lines up. The five versions of each letter still take turns.

# fibonacci, written by hand
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print(fib(10))   # 55

Download Stavan Mono

In VS Code, set "editor.fontFamily": "Stavan Mono" and "editor.fontLigatures": true (that second one switches the letter rotation on).

As handwritten notes

    
Type or paste your notes on the page and choose Save › Notebook pages. You get a PDF of ruled pages written in my hand, with the ink stored as pen strokes like GoodNotes does, so you can import it into GoodNotes or Notability and keep writing on it.


    
As a 3D print

    
Save › 3D print turns your page into an STL: every pen stroke becomes a tube on a thin plaque, like a small neon sign. Any slicer can print it. Switch the paper to neon to see it lit up.


    
With a real pen

    
The letters are pen paths, not outlines, so a pen plotter or laser can write them with a single line, the way I did. Download the single-line font and pick it in Inkscape under Extensions › Text › Hershey Text (choose “Other SVG font”). Animated SVGs saved from this page are single-line too and plot as they are.
